# Animations

`haskell/app/Video.hs`) and the specification is Lean (`lean/ContextualBandit/Video.lean`). This
folder holds the Manim scenes, one per take, made after the script is approved:

- `linha_do_tempo.py`: scene 1.2, *steal like an artist*.

The numbers the animations show come from [`../resultados.pt-BR.md`](../resultados.pt-BR.md),
written by `cabal run video`.
